# Discord Info Bot

Discord Info Bot is a Java-based Discord bot built with **JDA (Java Discord API)**. It provides users with quick information on **artists/bands**, **movies**, and **animes** by integrating with external APIs like **Spotify** and **MyAnimeList**. The bot also uses **JSON parsing**, **OkHttp**, **Gson**, and **Logback** for handling API responses, data serialization, and logging.

## Key Features
- Retrieve artist and band information via the **Spotify API**  
- Get movie details from various sources  
- Fetch anime information from **MyAnimeList**  
- Fast, reliable, and easy-to-use Discord commands  

## Technologies
- **Java 8+**  
- **JDA (Java Discord API)**  
- **Spotify API** integration  
- **MyAnimeList API** integration  
- **Gson & org.json** for JSON handling  
- **OkHttp** for HTTP requests  
- **Logback** for logging  
- **JUnit** for testing
